# 廿四牌局 · Twenty-Four Studio

一个零依赖的静态 24 点工作台。三块功能共用同一个精确求解器：

| 面板 | 做什么 |
| --- | --- |
| **Ⅰ 牌局擂台** | 随机发一手**保证有解**的牌，点牌拼算式，实时判定；可看全部打法、重摆牌面、另开一局 |
| **Ⅱ 解法审计** | 输入四个数（和目标数），列出**所有**算到目标的思路，并可展开未折叠的原始算式 |
| **Ⅲ 死局牌库** | 批量生成**怎么算都无解**的牌组，附「最接近值」证明与牌库全景统计 |

在线地址（push 后由 GitHub Actions 自动部署）：<https://yx333221c.github.io/twenty-four-studio/>

## 直接用

无任何构建步骤，双击 `index.html` 即可，或：

```bash
npm run serve        # http://127.0.0.1:8080
npm test             # 66 项断言，含 1820 种牌组穷举验证
npm run build:data   # 重新生成 js/data.js（牌库全景的预计算结果）
```

## 求解器为什么可信

`js/engine.js` 是手写求解器，不用浮点：

1. **BigInt 精确分数**。`5×(5−1÷5)` 这类题的中间值是 `24/5`，浮点会漂，这里恒等于 24。
2. **穷举**。每轮取两张牌 × 6 种有序运算（`+ × − − ÷ ÷`），四张牌共 `36 × 18 × 6 = 3888` 条推导路径，一条不漏。
3. **双层去重**，这是「列出所有方法」能不能看的关键：
   - *结构键*：把结合律、交换律展平成规范式，`(1+2)+3` 与 `3+(1+2)` 算一种；
   - *本质键*：再折叠恒等变形（`×1`、`÷1`、`+0`、`x−x`），于是 `1×11+13÷1`、`11+13×1`、`(11+13)÷(1×1)` 归为同一种思路。
   折叠只影响分组，**展示出来的每条算式仍然用满四张牌**，不会给你看半截式子。
4. **打印层单独验证**。括号规则处理了 `a−(b+c)`、`a÷(b×c)` 这类右子式必须保括号的情况；测试会把全部 4469 条已打印公式重新解析求值，逐条确认等式成立且恰好用掉那四张牌。

`npm test` 覆盖：经典难题（`1,5,5,5`、`3,3,7,7`、`3,8,3,8`）、已知死局、1820 种牌组的快慢双实现交叉验证（无解 458 组，与公开结论一致）、发牌器、算式检查器、分数精确性。

## 键盘

擂台页可直接敲键盘：`1`–`4` 出牌、`+ - * /` 与 `( )`、`⌫` 回退、`Esc` 清空、`Enter` 揭晓打法、`N` 换一局。

## 分享题目

解法审计里点「复制题目链接」，得到形如 `?audit=1,5,5,5&target=24` 的地址，对方打开即直达该结果。

## 数据与统计

`js/data.js` 由 `scripts/build-data.js` 在构建期穷举生成（扑克 A–K 与 1–9 两种牌面各一遍），所以「牌库全景」里的 1820 / 458 / 25.16% / 思路最多牌组等数字是算出来的，不是写死的，浏览器打开时也不会卡。

## 目录

```
index.html            三面板骨架
styles.css            牌桌视觉（绿绒 / 大理石两套配色）
js/engine.js          求解器（浏览器 + Node 双用）
js/data.js            预计算牌库全景（自动生成）
js/ui.js              交互控制器
scripts/build-data.js 数据生成器
scripts/serve.js      本地预览服务器
tests/engine.test.js  66 项断言
```
